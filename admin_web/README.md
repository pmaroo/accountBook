# FitTheWeb Admin Web

앱과 분리된 웹 관리자 페이지입니다.

## 목적

1. 카테고리 예산 관리
2. 목표 금액 관리
3. 금융 연동 상태 관리
4. 백업 JSON 불러오기 및 수정본 내보내기
5. 거래 데이터 검수

## 실행 방법

정적 웹 페이지이므로 브라우저에서 바로 열 수 있습니다.

### 가장 간단한 방법

`admin_web/index.html` 파일을 브라우저에서 열기

### 로컬 서버로 실행

Python이 있으면 아래처럼 실행할 수 있습니다.

```bash
cd /Users/bag-eunbi/fittheweb/app/admin_web
python3 -m http.server 5500
```

그 다음 브라우저에서:

```text
http://localhost:5500
```

## 데이터 구조

관리자 웹은 앱의 백업 JSON 구조와 호환되도록 설계되어 있습니다.

즉:

1. 앱에서 `백업 생성`
2. 관리자 웹에서 `백업 JSON 불러오기`
3. 값 수정
4. `수정본 백업 내보내기`
5. 앱에서 `백업 파일 선택`으로 복원

이 흐름으로 서버 없이도 운영 데이터를 조정할 수 있습니다.
