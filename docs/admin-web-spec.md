# 관리자 웹 분리 설계서

## 1. 목적

사용자용 Flutter 앱과 별도로, 운영자가 브라우저에서 관리할 수 있는 독립 관리자 웹을 제공한다.

구현 위치:

- `admin_web/index.html`
- `admin_web/styles.css`
- `admin_web/app.js`

## 2. 분리 이유

1. 운영자 화면과 사용자 앱 역할 분리
2. 앱 빌드 없이 운영 데이터 확인 가능
3. 백업 JSON 기반 수동 운영 가능
4. 향후 서버 API 연결 시 관리자 UI 재사용 가능

## 3. 현재 관리자 웹 기능

1. 대시보드 요약 카드
2. 예산 사용 집중 구간 시각화
3. 연동 상태 모니터링
4. 카테고리 편집
5. 목표 편집
6. 연동 공급자 상태 변경
7. 거래 검수 테이블
8. 앱 설정 변경
9. 백업 JSON 불러오기
10. 수정본 백업 JSON 내보내기
11. 브라우저 localStorage 임시 저장

## 4. 현재 데이터 흐름

1. 앱에서 백업 JSON 생성
2. 관리자 웹에서 불러오기
3. 운영 수정
4. 관리자 웹에서 JSON 내보내기
5. 앱에서 다시 복원

## 5. 향후 확장 방향

1. 관리자 로그인
2. 서버 저장
3. 운영자 권한 분리
4. 실시간 사용자 데이터 조회
5. 공지/알림 관리
6. 챌린지 운영 도구
