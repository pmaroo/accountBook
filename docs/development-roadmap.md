# 가계부 앱 개발 로드맵

## 1. 문서 목적

이 문서는 현재 구현 상태를 기준으로 다음 개발 우선순위를 단계별로 정리한 로드맵이다.

## 2. 현재 완료 범위

1. 기본 앱 구조
2. 홈/내역/자산/통계/설정 화면
3. 거래 CRUD
4. 카테고리 관리
5. 예산 계산
6. 절약 인사이트
7. 백업/복원
8. CSV 입출력
9. 로컬 알림
10. 금융 연동 상태/인증 시뮬레이션

## 3. 1순위 개발

### 실제 금융 인증 연결

목표:
현재 더미 인증 플로우를 실 OAuth 또는 마이데이터 흐름으로 교체

세부 작업:

1. 콜백 URL 설계
2. 인증 세션 상태 저장
3. 토큰 저장소 설계
4. 토큰 만료/갱신 처리
5. 공급자별 scope 정의

### 로그인/사용자 계정

목표:
기기별 로컬 앱에서 사용자 중심 앱으로 전환

세부 작업:

1. 로그인 화면
2. 사용자 세션 관리
3. 사용자별 백업 분리
4. 다중 기기 복원 대응

## 4. 2순위 개발

### 클라우드 백업

1. 백업 업로드
2. 백업 다운로드
3. 자동 백업 스케줄
4. 백업 이력 관리

### 차트 고도화

1. 실제 차트 패키지 적용
2. 터치 툴팁
3. 카테고리 선택 필터
4. 주간/월간 전환

### 목표/챌린지 확장

1. 챌린지 전용 화면
2. 챌린지 달성률 기록
3. 목표별 상세 화면
4. 월별 리포트 카드

## 5. 3순위 개발

### 운영 기능

1. 에러 로그 수집
2. 사용성 이벤트 추적
3. 앱 버전 체크
4. 공지/점검 메시지

### 품질 강화

1. 화면 테스트 확대
2. 상태 로직 단위 테스트 확대
3. 백업/복원 회귀 테스트
4. 동기화 중복 방지 테스트

## 6. 추천 일정 예시

### 1주

1. 로그인 구조
2. 사용자 세션 저장
3. 토큰 엔티티 설계

### 2주

1. OAuth 인증 시작/콜백 처리
2. 공급자별 권한 범위 연결
3. 인증 실패 처리

### 3주

1. 실제 거래/자산 조회 API 연결
2. 실데이터 동기화 검증
3. 중복 처리 강화

### 4주

1. 클라우드 백업
2. 기기 복원 플로우
3. 실사용 QA

## 7. 마감 기준 제안

### MVP 마감 기준

1. 수동 거래 입력 가능
2. 예산 초과 경고 가능
3. 자산/통계 확인 가능
4. CSV/백업 복원 가능

### 실서비스 1차 기준

1. 로그인 가능
2. 1개 이상 금융사 실연동 가능
3. 클라우드 백업 가능
4. 알림/복원 흐름 안정화
