# 가계부 앱 구현 기능 정리

## 1. 문서 목적

이 문서는 현재까지 구현된 기능을 정리한 개발 현황 문서다.
완성된 기능, 준비된 구조, 아직 남은 확장 항목을 구분해서 기록한다.

## 2. 현재 구현 완료 기능

### 2.1 앱 기본 구조

1. Flutter 프로젝트 초기 환경 구성
2. 메인 탭 5개 구조 구성
3. macOS 실행 프로젝트 추가
4. 웹 실행 지원
5. 공통 테마 적용

### 2.2 홈 대시보드

1. 월 수입/지출 요약 표시
2. 총 저축 금액 표시
3. 투자 원금 및 평가 금액 표시
4. 오늘 사용 가능 금액 계산
5. 카테고리별 예산 현황 표시
6. 전월 대비 지출 차이 표시
7. 이번 주 소비 속도 표시
8. 절약 우선순위 인사이트 표시
9. 챌린지 상태 표시

### 2.3 거래 내역 관리

1. 거래 내역 리스트 표시
2. 월별 그룹핑
3. 거래 추가
4. 거래 수정
5. 거래 삭제
6. 거래 상세 바텀시트
7. 제목/결제처 검색
8. 수입/지출/이체 필터
9. 자동 연동 거래와 수동 거래 구분 표시

### 2.4 자산/목표 관리

1. 연결 자산 목록 표시
2. 투자 수익 계산
3. 저축 목표 진행률 표시
4. 목표 금액 수정

### 2.5 통계/분석

1. 월별 지출 통계
2. 최근 3개월 추세 계산
3. 카테고리별 추세 표시
4. 자동 연동 비율 계산
5. 지난달 대비 증감 계산
6. 절약 인사이트 생성

### 2.6 예산/절약 로직

1. 카테고리별 월 예산 저장
2. 남은 예산 계산
3. 하루 사용 가능 금액 계산
4. 예산 초과 항목 표시
5. 절약 플랜 메시지 생성

### 2.7 챌린지/알림

1. 하루 소비 챌린지 데이터 표시
2. 알림 메시지 생성 로직 구현
3. 로컬 알림 테스트 발송 구현
4. 경고/주의/정보 레벨 구분

### 2.8 카테고리 관리

1. 카테고리 추가
2. 카테고리 수정
3. 카테고리 삭제
4. 사용 중 카테고리 삭제 방지
5. 고정 항목 여부 관리

### 2.9 데이터 저장

1. 모바일/데스크톱 SQLite 저장
2. 웹 SharedPreferences 저장
3. 테스트용 메모리 저장소
4. 앱 전체 상태 직렬화
5. DB 마이그레이션 기초 적용

### 2.10 데이터 이동

1. 거래 CSV 내보내기
2. 최신 CSV 가져오기
3. 파일 선택 CSV 가져오기
4. 전체 상태 백업 JSON 생성
5. 최신 백업 복원
6. 파일 선택 백업 복원
7. 거래 중복 가져오기 방지

### 2.11 금융 연동 구조

1. 금융 커넥터 인터페이스 정의
2. 더미 은행/카드/증권 커넥터 구현
3. 공급자별 연결 상태 저장
4. 권한 허용 여부 저장
5. 마지막 동기화 시각 저장
6. 인증 상태 저장
7. 최근 인증 시각 저장
8. 인증 오류 상태 저장
9. 연동 인증 관리 화면 구현
10. 인증 요청/권한 승인/연결 해제 흐름 구현

## 3. 현재 준비된 기술 구조

### 3.1 상태 및 도메인

1. 앱 전역 상태 컨트롤러 구성
2. 예산/거래/자산/목표/연동 공급자 모델 정의
3. 대시보드 스냅샷 계산 구조 구성

### 3.2 서비스 계층

1. 알림 서비스
2. 로컬 알림 서비스
3. CSV/백업 입출력 서비스
4. 금융 커넥터 서비스

### 3.3 플랫폼 대응

1. 웹/비웹 분기 저장소
2. 웹/비웹 분기 내보내기 서비스
3. 웹/비웹 분기 로컬 알림 서비스

## 4. 현재 구현된 문서화 가능한 사용자 흐름

1. 수동 거래 입력 후 저장
2. 거래 상세 확인 후 수정/삭제
3. 카테고리 생성 및 예산 설정
4. CSV 파일 내보내기
5. CSV 파일 선택 후 거래 가져오기
6. 백업 파일 생성
7. 최신 백업 복원
8. 백업 파일 선택 복원
9. 연동 공급자 인증 시작
10. 권한 승인 반영
11. 연결된 공급자 즉시 동기화
12. 로컬 알림 테스트 발송

## 5. 아직 실제 연동 전 단계인 기능

아래 기능은 화면과 상태 구조는 준비되어 있지만, 실제 외부 서비스 연결은 아직 더 필요하다.

1. 실제 은행 API 연동
2. 실제 카드사 API 연동
3. 실제 증권사 API 연동
4. OAuth 또는 마이데이터 인증 콜백 처리
5. 실제 토큰 저장 및 갱신
6. 서버 연동 기반 사용자 로그인
7. 클라우드 백업

4. 클라우드 백업/복원
