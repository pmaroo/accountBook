# 가계부 앱 화면 정의서

## 1. 문서 목적

이 문서는 Flutter 기반 가계부 앱의 주요 화면 구조와 화면별 핵심 기능을 정리한 화면 정의서다.
현재 앱은 `홈`, `내역`, `자산`, `통계`, `설정` 5개 메인 탭과 연동 인증 전용 화면으로 구성된다.

## 2. 전체 화면 구조

### 메인 탭

1. 홈
2. 내역
3. 자산
4. 통계
5. 설정

### 서브 화면

1. 거래 추가/수정 바텀시트
2. 거래 상세 바텀시트
3. 카테고리 추가/수정 바텀시트
4. 금액 수정 다이얼로그
5. 연동 인증 관리 화면
6. 연동 인증 바텀시트

## 3. 화면 상세

### 3.1 홈 화면

목적:
사용자가 이번 달 소비, 남은 예산, 저축/투자 상태, 절약 우선순위를 한눈에 확인하는 대시보드 화면

주요 표시 정보:

1. 이번 달 총 수입
2. 이번 달 총 지출
3. 총 저축 금액
4. 투자 원금 및 평가 금액
5. 오늘 사용 가능 금액
6. 카테고리별 예산 진행률
7. 전월 대비 지출 변화
8. 이번 주 소비 속도
9. 절약 우선순위 인사이트
10. 챌린지 상태

주요 액션:

1. 현재 재정 상태 빠른 확인
2. 절약이 필요한 항목 식별
3. 예산 초과 카테고리 확인

### 3.2 내역 화면

목적:
거래 내역을 검색, 필터링, 추가, 수정, 삭제하고 CSV로 내보내거나 가져오는 화면

주요 표시 정보:

1. 이번 달 총 지출
2. 자동 연동 거래 수
3. 수동 입력 거래 수
4. 월별 그룹 거래 리스트
5. 거래 제목, 금액, 날짜, 입력 방식

주요 액션:

1. 거래 추가
2. 거래 상세 확인
3. 거래 수정
4. 거래 삭제
5. 검색
6. 유형 필터
7. CSV 내보내기
8. 최신 CSV 가져오기
9. 파일 선택 CSV 가져오기

### 3.3 자산 화면

목적:
저축 목표와 투자 자산 상태를 한눈에 확인하는 화면

주요 표시 정보:

1. 총 보유 자산
2. 총 저축액
3. 투자 원금
4. 현재 평가 금액
5. 수익 금액
6. 수익률
7. 목표별 진행률
8. 연결 자산 목록

주요 액션:

1. 저축/투자 현황 확인
2. 목표 진행률 확인

### 3.4 통계 화면

목적:
월별 소비 흐름과 카테고리별 소비 추세를 분석하는 화면

주요 표시 정보:

1. 월별 지출 추이
2. 카테고리별 소비 비중
3. 최근 3개월 소비 흐름
4. 카테고리별 추세
5. 자동 연동 비율
6. 지난달 대비 지출 차이
7. 절약 인사이트 요약

주요 액션:

1. 소비 패턴 분석
2. 월별 변화 확인
3. 절약 전략 점검

### 3.5 설정 화면

목적:
앱 동작, 카테고리, 알림, 백업/복원, 연동 관리 진입을 담당하는 설정 화면

주요 표시 정보:

1. 알림 미리보기
2. 카테고리 목록
3. 연동 서비스 목록
4. 앱 동작 설정
5. 백업/복원 액션

주요 액션:

1. 로컬 알림 테스트 발송
2. 백업 생성
3. 최신 백업 복원
4. 백업 파일 선택 복원
5. 카테고리 추가/수정/삭제
6. 자동 동기화 on/off
7. 절약 플랜 추천 on/off
8. 챌린지 리마인더 on/off
9. 연동 인증 관리 화면 이동
10. 샘플 데이터 초기화

### 3.6 연동 인증 관리 화면

목적:
은행/카드/증권 앱 연동 상태와 인증 단계를 관리하는 전용 화면

주요 표시 정보:

1. 금융사 이름
2. 인증 상태
3. 상태 메시지
4. 최근 인증 시각
5. 최근 동기화 시각
6. 연결 여부
7. 권한 승인 여부

주요 액션:

1. 인증 관리 진입
2. 인증 요청 시작
3. 권한 승인 반영
4. 연결 해제
5. 즉시 동기화

## 4. 공통 화면 요소

### 바텀 네비게이션

1. 홈
2. 내역
3. 자산
4. 통계
5. 설정

### 공통 입력 패턴

1. 거래 추가/수정은 바텀시트
2. 카테고리 추가/수정은 바텀시트
3. 금액 변경은 다이얼로그
4. 세부 액션 결과는 스낵바로 안내

## 5. 상태 색상 규칙

1. 예산 정상 범위는 기본/초록 계열
2. 예산 경고는 주황 계열
3. 예산 초과/오류는 빨간 계열
4. 연결 완료는 초록 계열
5. 인증 필요는 파란 계열
6. 본인 확인 대기는 주황 계열
